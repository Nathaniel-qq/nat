## 📚 Included Courses & Syllabi

1. **CSNS 141 – Digital Electronics** (Floyd Style + Ghana University Focus)
   - Number systems, radix conversions, fractional binary, 1's/2's complements
   - Logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) and Boolean algebra laws
   - 3-variable & 4-variable K-Map simplification
   - Combinational logic: Half/Full Adders, Subtractors, 2:1/4:1/8:1 Multiplexers, Decoders (BCD to 7-segment)
   - Sequential logic: SR, JK, D, T Flip-flops, Race-around condition, Master-Slave, MOD-N counters, SISO/SIPO/PISO/PIPO shift registers
   - Memory hierarchy, SRAM vs DRAM, PROM, EPROM, EEPROM, Flash memory

2. **MATH 105 – Linear Algebra** (Ghana University Exam Edition)
   - Matrix operations, 2×2 and 3×3 determinants by cofactor expansion, inverse formula $A^{-1} = \frac{1}{\det(A)}\text{Adj}(A)$
   - Systems of linear equations, Elementary Row Operations, Gaussian elimination
   - Vector spaces, 3-step subspace test, linear independence, basis, dimension
   - Rank-Nullity Theorem: $\text{Rank}(A) + \text{Nullity}(A) = n$
   - Linear transformations, Kernel (Null space), Range (Column space), Dimension Theorem
   - Eigenvalues $\det(A - \lambda I) = 0$, Eigenvectors, Diagonalization $A = PDP^{-1}$, Cayley-Hamilton theorem
   - Applications to Computer Science: 2D/3D Graphics, Google PageRank, PCA, Cryptography

3. **CSPC – Physics for Computing Systems** (Exam Edition)
   - Measurements, SI base units, scientific notation
   - Kinematics equations of motion, Newton's 3 laws of motion, momentum
   - Work, energy (KE, PE), conservation of energy, mechanical and electrical power ($P = VI = I^2R = V^2/R$)
   - Electrostatics, Coulomb's Law, capacitance ($Q = CV$)
   - Current electricity, Ohm's Law ($V = IR$), series & parallel networks, Kirchhoff's laws (KCL & KVL)
   - Semiconductors, doping (N-type vs P-type), PN junction diodes, BJT transistors
   - Magnetism, Faraday's Law ($\text{EMF} = -N \frac{d\Phi}{dt}$), Lenz's Law, transformers
   - Waves ($v = f\lambda$), EM spectrum, communication systems, energy band gap theory

4. **CSSD 111 – Introduction to Computer Science**
   - Computer definition, IPO cycle (Input-Processing-Output-Storage), characteristics
   - Pioneers (Pascal, Charles Babbage, Ada Lovelace) and 5 Computer Generations
   - Hardware: CPU (ALU, CU, Registers), primary memory (RAM vs ROM), secondary storage
   - Software: System, Application, Utility, Compilers vs Interpreters vs Assemblers
   - Data measurement units: bit, nibble, byte, KB, MB, GB, TB
   - Operating systems functions, process scheduling, memory & file management
   - Computer networks (LAN, MAN, WAN), network hardware (Hub, Switch, Router), WWW vs Internet
   - Problem solving, standard flowchart symbols, pseudocode
   - Computer ethics, malware (Virus vs Worm vs Trojan), cyber security defenses

5. **CSSD 101 – Programming and Problem Solving**
   - Problem solving methodology and algorithm traits (Finiteness, Definiteness, Input, Output, Effectiveness)
   - Flowcharts, decision branching, pseudocode conventions
   - Data types, variable naming rules, arithmetic operators including modulus (`%`)
   - Decision structures: IF, IF-ELSE, Nested IF
   - Looping structures: FOR (counter-controlled), WHILE (pre-test), REPEAT-UNTIL (post-test)
   - Functions, parameter passing, return values, local vs global scope
   - Arrays: Contiguous memory allocation, 0-based indexing
   - Error types: Syntax, Runtime, Logical errors; 7 stages of PDLC

6. **FREN 171 – Basic French**
   - French alphabet, phonetics, and 5 accents (aigu, grave, circonflexe, cédille, tréma)
   - Greetings, courtesy expressions, formal and informal self-introduction
   - Cardinal numbers 0 to 100, days of the week, months, and telling time
   - Definite (*le, la, l', les*) and indefinite (*un, une, des*) articles
   - Subject pronouns and full present conjugations of **ÊTRE** and **AVOIR**
   - Regular -ER first-group verb pattern (**PARLER**, **AIMER**, **ÉTUDIER**)
   - Question formation (*Est-ce que*, inversion, question words) and negation (*ne ... pas*)
   - Adjective gender/number agreement, family terms, classroom vocabulary

7. **CTGE 121 – Introduction to Electronics**
   - Atomic structure, energy bands, conductors, insulators, intrinsic & extrinsic semiconductors
   - Resistor 4-band color code mnemonic (*BBROYGBVGW*)
   - Circuit analysis: Ohm's law, series/parallel reductions, KCL and KVL
   - PN junction diodes, barrier potentials (0.7V Si, 0.3V Ge), forward/reverse bias, LEDs, Zener regulators
   - Rectifiers: Half-wave, Full-wave bridge (4 diodes, 81.2% efficiency), capacitor filters, 7805 regulator
   - BJT transistors: Emitter, Base, Collector, $I_E = I_B + I_C$, Cutoff and Saturation switching states
   - IC classifications: SSI, MSI, LSI, VLSI, ULSI

8. **ENGL 171 – Communication Skills I**
   - 5 elements of communication: Sender, Message, Channel, Receiver, Feedback
   - Verbal, non-verbal (kinesics, proxemics, paralanguage), written, and visual communication
   - Physical, semantic/linguistic, psychological, and cultural barriers
   - Active listening vs passive hearing; Reading strategies: Skimming, Scanning, Intensive, Extensive
   - Sentence types (Simple, Compound, Complex); Subject-Verb agreement (Concord)
   - Paragraph writing (Topic sentence, Supporting details, Conclusion); 4 Essay genres
   - Professional writing: Formal letters (*Dear Sir/Madam* $\rightarrow$ *Yours faithfully*), Reports, CVs

9. **MATH 103 – Discrete Mathematics for Computer Science**
   - Propositional logic, connectives ($\neg, \land, \lor, \oplus, \rightarrow, \leftrightarrow$), truth tables, tautologies, rules of inference (Modus Ponens, Modus Tollens)
   - Proof techniques: Direct proof, Contrapositive, Contradiction, Mathematical Induction
   - Set theory, power sets ($|P(A)| = 2^n$), Inclusion-Exclusion Principle
   - Binary relations: Reflexive, Symmetric, Antisymmetric, Transitive; Equivalence relations & Posets
   - Functions: Injective (one-to-one), Surjective (onto), Bijective, inverse functions
   - Counting: Fundamental product rule, Permutations ($nPr$), Combinations ($nCr$), Pigeonhole Principle
   - Classical, conditional, and Bayes' Theorem probability
   - Recurrence relations: Fibonacci, characteristic roots
   - Graph theory: Handshaking Theorem ($\sum \text{deg}(v) = 2|E|$), trees ($|E| = |V| - 1$), BFS (Queue) vs DFS (Stack)
